# 進学支援ナビ Ver.0

高校生が、進学にかかるお金の支援制度を知り、次にやることを整理するためのWebアプリ。

## 動かすまで（初めての人向け）

### 1. Node.js を入れる

まだ入っていなければ https://nodejs.org/ から LTS 版をダウンロードしてインストールする。
入っているか確かめるには、ターミナル（Windowsなら PowerShell）で次を実行する。

```
node -v
```

`v20.x.x` のような数字が出れば入っている。

### 2. このフォルダに移動する

zipを展開した場所に合わせてパスを書き換える。

```
cd ~/Downloads/shingaku-navi
```

### 3. 必要な部品を取ってくる（初回だけ）

```
npm install
```

数十秒かかる。`node_modules` というフォルダができるが、これは自動生成されるものなので中身を触らなくてよい。

### 4. 起動する

```
npm run dev
```

`http://localhost:5173` のようなURLが表示されるので、ブラウザで開く。
コードを保存すると、画面が自動で更新される。止めるときはターミナルで `Ctrl + C`。

スマホでの見え方を確認したいときは、ブラウザの開発者ツールでスマホ表示に切り替える（Chromeなら `Cmd/Ctrl + Shift + M`）。

## 変更したあとの確認（とても大切です）

コードを変えたら、次のコマンドを実行してください。**これ1つだけ覚えれば大丈夫です。**

```
npm run check
```

これは3つのことを順番に実行します。1つでも失敗したら、そこで止まります。

| 順番 | 内容 | 何を見ているか |
| --- | --- | --- |
| 1 | `npm run lint` | 書き間違い、使っていない変数、スマホで使えなくなる書き方 |
| 2 | `npm test` | 画面が正しく動くか、危険な表現が混ざっていないか |
| 3 | `npm run build` | 公開用のファイルが作れるか |

### 個別に実行したいとき

```
npm run lint       コードの検査だけ
npm test           テストだけ（数秒で終わります）
npm run test:watch テストを開きっぱなしにする（保存するたび自動で再実行）
npm run build      公開用ファイルを作るだけ
```

### スマートフォン表示の確認

本物のブラウザを動かして、スマホでの見え方を確認します。

```
npm run test:e2e
```

**初回だけ**、ブラウザのダウンロードが必要です。

```
npx playwright install chromium
```

このテストが見ているのは、ふつうのテストでは測れないことです。

- 画面が横にはみ出していないか
- ボタンが指で押せる大きさ（高さ44px以上）か
- 公式サイトへのリンクが安全な設定になっているか
- 読み込み時にエラーが出ていないか

### テストが失敗したら

**テストを消して通すことは絶対にしないでください。** テストは「前はできていたこと」を覚えている記録です。失敗したということは、何かを壊した可能性が高いということです。

エラーメッセージは日本語で、どこが問題かを説明するように書いてあります。まずそれを読んでください。

### 安全性のテストについて

`tests/safety.test.js` は、「受給できます」のように**受け取れることを断定する表現**がコードやデータに混ざっていないかを自動で検査します。

単語で禁止しているのではなく、言い回しで判断しています。

| 書き方 | 判定 |
| --- | --- |
| 「必ず公式サイトで確認してください」 | ✅ 問題なし（むしろ書くべき文章） |
| 「必ずもらえます」 | ❌ エラー（受け取れると断定している） |
| 「対象になる場合があります」 | ✅ 問題なし |
| 「あなたは対象です」 | ❌ エラー（言い切っている） |

ルールを追加したいときは `tests/helpers/dangerousPhrases.js` を編集し、
`tests/safety.test.js` の「危険な文章の例」と「安全な文章の例」の**両方**に文例を足してください。
両方に足すことで、新しいルールが正しい文章まで巻き込んでいないかを確認できます。

## Claude Code で開発を続ける

このフォルダを指定して Claude Code を起動する。

```
cd ~/Downloads/shingaku-navi
claude
```

同じフォルダにある `CLAUDE.md` を Claude Code が自動で読む。
プロジェクトの目的、守るべき安全上の原則、ファイルの役割が書いてあるので、毎回説明し直さなくてよい。

インストール手順は https://code.claude.com/docs を参照。

## 最初にやるとよいこと

`src/ShingakuNavi.jsx` の一番上にある `SHIENDATA` が支援制度のデータ。
いま入っている7件はすべてサンプルで、`verified: false` になっているため画面上に「サンプルデータ」と表示される。

公式サイトで内容を確認した制度から `verified: true` に変え、実際の制度に置き換えていく。
書き方と、使える条件の一覧は `SHIENDATA` の直前のコメントに書いてある。

金額・所得基準・締切はデータに入れない。古い情報が残ると、利用者が判断を誤るため。

## ファイル構成

```
index.html                        ページの入れ物
package.json                      使っている部品と、実行できるコマンドの一覧
vite.config.js                    ビルドとテストの設定
eslint.config.js                  コード検査の設定
playwright.config.js              スマホ表示テストの設定
CLAUDE.md                         Claude Code 向けのプロジェクト説明
public/favicon.svg                ブラウザのタブに出るアイコン

src/main.jsx                      アプリの起動
src/index.css                     背景と高さだけの最小限のCSS
src/ShingakuNavi.jsx              アプリ本体

tests/setup.js                    テストの下準備
tests/screens.test.jsx            画面と操作のテスト
tests/safety.test.js              危険な表現が混ざっていないかのテスト
tests/helpers/dangerousPhrases.js 危険な言い回しを見つける仕組み
tests/e2e/flow.spec.js            スマホ表示のテスト
```

## 公開するとき

```
npm run build
```

`dist` フォルダができる。これを Vercel や Netlify にアップロードすると、URLで他の人がスマホから開ける。
